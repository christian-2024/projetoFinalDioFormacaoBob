# Comandos de estudo

Este workspace disponibiliza comandos personalizados para o Copilot Chat. Abra o chat e use `/trilha`, `/desafio` ou `/certificado`.

- `/trilha`: informe uma tecnologia para consultar `data/trilhas_dio.json` e receber os módulos da trilha correspondente.
- `/desafio`: informe uma tecnologia e um nível (iniciante, intermediário ou avançado) para receber um desafio de código.
- `/certificado`: informe o nome da pessoa e a trilha concluída para gerar um certificado fictício em Markdown. O documento não é oficial nem emitido pela DIO.

Os comandos estão em `.github/prompts/` e são reconhecidos como prompts personalizados pelo VS Code.
